# Moraja3a
«moraja3a» تطبيقٌ تعليميّ مستقلّ يساعد أساتذة التعليم الابتدائي على تصفّح مجلّد الموادّ التعليمية («عدة العمل») المحفوظ على أجهزتهم، وفتح وثائقه، وإرسال طلبات الطباعة إلى إدارة المؤسسة. التطبيق من تصميم الأستاذ ابراهيم وربع بصفة فردية، وليس منتجاً رسميّاً صادراً عن الوزارة أو الأكاديمية أو المديرية.
